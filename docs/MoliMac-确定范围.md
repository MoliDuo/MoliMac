# MoliMac 确定范围（第一版）

> 2026-10-05 确定。完整调研资料见 [MoliMac-功能清单.md](MoliMac-功能清单.md)，那份只作参考。

## 前提

- **只支持 macOS 27。**
- **使用环境：**
  - 罗技 G Pro 无线鼠标：5 个键，可自定义的是中键和两个侧键。
  - 键盘。
  - 笔记本一直合盖，只接一台外接显示器。
  - 不用触控板，屏幕没有刘海。
- **大模块各自可以单独开关：** Dock 预览、窗口切换、鼠标、状态栏。

## 一、基础（默认就做）

- **外壳**
  - 菜单栏图标，菜单里可以一键暂停某个模块。
  - 开机启动。
  - 权限引导：辅助功能必需，录屏权限用于显示缩略图。
  - 权限被撤销时自动释放鼠标和键盘的拦截，防止输入卡死。
  - 睡眠、换显示器之后自动恢复。
  - 恢复默认设置。
- **统一动作库**：Dock 预览、切换器、鼠标按键、快捷键都调用同一套窗口和系统动作。
- **Dock 预览**
  - 悬停 Dock 图标，显示该 App 所有窗口的缩略图。
  - 包括其他桌面上的窗口和最小化的窗口。
  - 自动过滤没用的「垃圾窗口」。
  - 点缩略图切到那个窗口，中键点缩略图关闭窗口。
  - 缩略图上有关闭、最小化、全屏按钮。
  - 弹出延迟可以调。
- **窗口切换（接管 ⌘Tab）**
  - ⌘Tab 弹出 MoliMac 的切换器，每个窗口一张缩略图。
  - 要秒开，默认先选中上一个窗口。
  - Tab、⇧Tab、方向键、回车、Esc 都能用。
  - 指定的 App 全屏时（比如游戏、虚拟机）不拦截 ⌘Tab。
- **鼠标**
  - 平滑滚动，滚动速度分档，滚动方向可以单独反转。
  - 按住修饰键滚动：缩放、横向、精确、快速。
  - 中键和侧键可以绑定动作，按法分单击、双击、按住、按住拖动、按住滚动。
  - 可绑定的动作包括后退/前进、切换桌面、调度中心、快捷键，以及 MoliMac 自己的功能。
  - 关闭指针加速，调节指针速度。
  - 可以列出不生效的 App。
- **状态栏**
  - 一键收起或展开图标，过一会儿自动收回。
  - 兼容系统自带的「按住 ⌘ 拖动」排序。

## 二、选中的可选功能

| # | 功能 | 效果 |
|---|---|---|
| 1 | 点前台 App 的 Dock 图标就最小化 | 再点一次就恢复 |
| 2 | 在 Dock 图标上滚滚轮 | 依次切换这个 App 的窗口 |
| 3 | 中键点 Dock 图标 | 新开一个窗口 |
| 4 | 拖文件停在缩略图上 | 自动切到那个窗口，方便直接放进去 |
| 7 | 切换器里打字搜索 | 按窗口标题或 App 名过滤 |
| 8 | ⌘Tab 切全部窗口，⌘` 只切当前 App 的窗口 | 由 ⌥Tab / ⌥` 改成 ⌘ 键位 |
| 10 | 右 ⌘ + 首字母，秒切某个 App | App 没打开就启动它 |
| 12 | 按住修饰键，左键拖窗口任意位置移动，右键拖调整大小 | 不用找标题栏或窗口边缘 |
| 13 | Dock 自动隐藏后弹出更快 | 弹出延迟和动画速度可以调 |
| 17 | 不同 App 用不同的鼠标设置 | 继承全局设置，只改需要改的部分 |
| 18 | 按一下中键后移动鼠标，页面自动滚动 | Windows 浏览器那种自动滚动 |
| 24 | 鼠标停在菜单栏上就展开隐藏的图标 | 不用去点展开按钮 |
| 26 | 正在用摄像头或麦克风的 App，图标永不隐藏 | 隐私考虑 |
| 27 | 缩小菜单栏图标之间的间距 | 改完要注销重新登录才生效 |

## 三、不做（第一版）

**环境用不上：**

| 不做的功能 | 原因 |
|---|---|
| 多显示器相关（每块屏都显示切换器、Dock 固定在某块屏） | 只有一台显示器 |
| 触控板手势、三指点击当中键 | 不用触控板 |
| 菜单栏下方的第二栏 | 没有刘海 |
| 罗技 MX 系列的拇指滚轮和手势键 | 鼠标是 G Pro，没有这些键 |
| 在系统 ⌘Tab 上叠加窗口 | 已经决定直接接管 ⌘Tab |

**你没选的：**

| # | 功能 |
|---|---|
| 5 | 在原位置预览窗口的原尺寸画面 |
| 6 | Dock 文件夹悬停预览 |
| 14 | 在标题栏上滚滚轮 |
| 19 | 关闭「越滚越快」 |
| 21 | 显示鼠标电量 |
| 25 | 搜索菜单栏图标 |
| 28 | 屏幕共享时隐藏图标 |

**默认就砍掉的：**
- 音乐和日历小组件
- 窗口贴边分屏（建议用 Rectangle）
- 光标特效
- 状态栏的配置方案和自动触发规则
- 大量外观调节选项
